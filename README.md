# 🚀 بوابة دخول ميكروتيك احترافية (HUSSEIN-STAR Captive Portal)

واجهة دخول ميكروتيك (Captive Portal) حديثة واحترافية متوافقة تماماً مع جميع أجهزة MikroTik، مصممة بأحدث معايير UI/UX لتوفير تجربة مستخدم سلسة وعصرية.

---

## ✨ المميزات الرئيسية
- 🎨 **تصميم عصري (Glassmorphic):** خلفية سماء ليلية متحركة مع نجوم وشهاب متساقط وإطار مموه أنيق.
- ⚙️ **ملف إعدادات merkezi (`app-config.js`):** التعديل السهل والسريع على اسم الشبكة، اللوجو، وأرقام التواصل دون المساس بالكود الأساسي.
- 📢 **مساحة إعلانية ديناميكية:** بنر إعلاني مدمج قابل للتفعيل والربط بروابط خارجية أو واتساب لزيادة الأرباح.
- 📱 **متوافق مع الهواتف:** استجابة كاملة مع مختلف الشاشات والأجهزة (Mobile Friendly).
- ⚡ **سريع ومستقر:** كود خفيف جداً ومحسن للعمل مباشرة على ذاكرة الميكروتيك دون استهلاك للموارد.

---

## 🛠️ كيفية التعديل المباشر (`app-config.js`)
